# profile 示範

`profiles/<專案主題>/` 放這個技能在某個專案的私人內容。資料夾名稱要等於專案主題的名稱（例如 `project-demo`），裡面可以連到那個專案主題的頁。公開輸出時，`profiles/` 整個拿掉，換成這個資料夾。

這裡放去識別化的示範，讓別人知道要準備哪些檔案、每個欄位是什麼意思。不可以出現業主、案名、設計單位、人名、圖號、本機路徑。

| 檔案 | 放什麼 | 公開版 |
|---|---|---|
| `conventions.md` | 圖號規則、編號族、圖層命名這類換專案就會變的慣例 | 換成這裡的示範 |
| `config.json` | 腳本參數 | 換成這裡的示範 |
| `cases.md` | 案件經驗、圖面錯誤紀錄 | 不輸出 |
| `denylist.txt` | 不能出現在公開版的字，一行一個 | 不輸出 |
