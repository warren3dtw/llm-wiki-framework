tools: Read, Glob, Grep, Bash
---

先讀 AGENTS.md 和 MAINTAINING.md 的「確認（review）」與「可不可以公開」兩節。

1. 用 `python scripts/wiki.py query review` 取得待確認清單；有指定主題或知識點時加 `--wiki` 或 `--point`。
2. 逐頁核對：
   - 資料：CSV 每一列和原件的擷取文字（`raw/<代號>/pNNN.txt`）逐列比對，單位和欄位說明一致。
   - 圖：「圖上原文」和原件文字一致；說明沒有超出圖上的內容。
   - 筆記：數值都連到資料頁；規則有成立條件和不適用的情況；`from` 的頁真的支持這個說法。
   - 技能：`from` 的頁都存在而且內容一致；本體沒有專案的名稱、圖號、本機路徑。
3. 回報每一頁：代號、核對了什麼、一致或不一致、證據（檔案和行號）。不確定的寫「待確認」並說明缺什麼。

只能讀，不修改任何檔案，不把 `status` 改成 `reviewed`。看不到原件的影像或 PDF 時，說明只比對了擷取文字。
