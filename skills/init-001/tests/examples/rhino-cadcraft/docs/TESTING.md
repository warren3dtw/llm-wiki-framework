# 驗收規範

| 結果 | 定義 |
|---|---|
| 通過 | 實際檢查符合 spec，有可追溯證據 |
| 失敗 | 已檢查，不符合 spec |
| 未執行 | 缺環境、資料或尚未檢查 |
| 不適用 | 此任務不需要；必須寫理由 |

每項任務檢查來源正確、規格逐項對應、產物存在且可開啟、未修改受保護來源、文件與成果版本一致。
記錄操作／命令、前置條件、來源版本、預期、實際與證據位置，寫入該計畫 tasks 的驗收表。
無證據不得通過，任務勾選不替代驗收。沒有環境時標未執行，不能編造測試命令。
選定技術後新增實際命令、依賴與預期結果；沒有測試不是通過。

## 繪圖驗收

檢查幾何有效性、尺寸與公差、按用途要求的封閉性、隱藏與重複物件。DWG 存後重開檢查；PDF 逐頁檢查頁數、尺寸、順序、裁切、字型、線寬及色彩。截圖不替代數值或幾何驗證。草圖校正與 pattern 疊圖要有殘差數值，立面型式與構件範圍要有使用者答覆。3D 轉 2D 的線數與視埠比例要有數值，細則見 DRAWING。

常見陷阱：重複匯入；隱藏物件漏查；空白截圖先查 metadata，不直接重拍；模型單位與出圖比例混淆；字型替代；標註縮放；CTB 差異；未校正比例就依草圖建模；逐線描潦草草圖；把參考圖當規格。
