# AI 專案空結構

此專案已建立 AI 工作空結構，尚未建立功能或交付成果。

1. 閱讀[專案資料](docs/PROJECT.md)，提供目標與交付要求。
2. AI 依[工作流程](docs/DEVELOPMENT.md)確認本次必要資訊。
3. 使用[計畫模板](docs/templates/plan.md)建立第一個計畫。
4. 依[驗收規範](docs/TESTING.md)執行並記錄證據。
5. [文件總入口](docs/README.md)。

第一個任務可以這樣提出：「請依 docs 工作，先整理我的需求及待確認事項，再建立計畫；我的目標是……」。

無軟體連線仍可整理需求和計畫。這是未連線環境的空結構示例，複製使用後按實際環境更新專案資料。
