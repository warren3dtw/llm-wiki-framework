# Rhino 模型操作

主要使用既有建築模型，不為動畫重建。尺寸、單位、公差、原點與軟體版本讀 [PROJECT](PROJECT.md)；未知工程值不採常見值。
任務要新建幾何時預設點→線→面→體：每層只由上一層建立，不跳層；元素依點、線、面、體分層保留，查詢時包含隱藏物件。用途只需線或面時可停止，不強迫封閉實體。

## 操作流程

1. 以不啟動實例的唯讀工具定位實例與文件；沒有實例不為初始化啟動 Rhino。
2. 查來源、文件單位、規格與本次輸出範圍；含隱藏、鎖定、重複及輔助物件，不能只看選取或畫面。
3. 依 [DEVELOPMENT](DEVELOPMENT.md) 判 task／spec 備份；來源唯讀，工作檔正常存 models/。
4. 修改前取 context；腳本用 MCP 實作提供的文件參照（原介面為 __rhino_doc__），不猜作用中文件。
5. 修改後檢查幾何、數量、GUID、圖層、group 與視圖；階段存檔要有實檔、SHA256、工具與來源版本及下一步。
6. 編號與匯出讀 [ASSEMBLY](ASSEMBLY.md)；影片觀感不能代替幾何檢查。

## MCP 操作

以下是原 Rhino MCP 介面的注意事項，使用前核對當前實作的 schema 與說明，差異記入 PROJECT：

- save_doc 可直接覆寫；close_doc 不帶 path、close_slot 可能丟棄未存內容，關閉前確認已存。
- open_doc 可能是匯入；clearFirst 可能清空物件，不把它當唯讀開檔。
- 明確定位 slot；不關閉使用者管理的實例。
- run_command 前查可用指令及參數；ask_user 若非同步，送出不代表收到答覆。
- 視圖截圖可能超過工具回傳上限，先查工具結果檔；取不到圖片時視覺驗證標未執行，不判定模型不存在。

## 建模檢查

- 驗證數值超標時先查原因，分清是模型問題或公式問題，不放寬標準。
- 版本相關案例只記版本，不作全域預設；其他版本需重新查證。
