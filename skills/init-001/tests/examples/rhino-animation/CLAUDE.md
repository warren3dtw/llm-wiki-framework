# AI 工作入口

- 每次開始先讀 [docs 索引](docs/README.md)、[專案資料](docs/PROJECT.md)、[工作流程](docs/DEVELOPMENT.md)；續作先讀目前計畫的 plan、specs、tasks。
- 專案模式、事實與數值只以 PROJECT 為準。
- 先補本次必要資訊再執行，不猜測指令、尺寸、公差、版本或工具名稱。
- 修改前記錄規格與任務，修改後驗收；未執行的檢查不得標通過。
- 來源不覆寫，交付使用未使用的新版本；結束同步 FEATURES、CHANGELOG 與計畫。
- 完成整個對話任務後自動 commit 本次變更，不自動 push；細則見 DEVELOPMENT。
- 未登記額外 skills；本空結構不依賴額外 skill。

動畫任務另讀 [MODELING](docs/MODELING.md)、[ASSEMBLY](docs/ASSEMBLY.md)、[ANIMATION](docs/ANIMATION.md)、[DELIVERY](docs/DELIVERY.md)。先在 Rhino 編號，使用者核准後才匯出。

新增 skill 採「前綴-三位數」，同一前綴由 001 起算且不重複。name 與指令使用編號，例如 init-001、rhino-001；資料夾採「編號-全名」，例如 rhino-001-rhino script；只登記實際已安裝項目。

所有問題與調整記入 [FEEDBACK](docs/FEEDBACK.md)。Task 小調整不備份模型；只有 spec 等級變更前備份一次，細則見 DEVELOPMENT。
