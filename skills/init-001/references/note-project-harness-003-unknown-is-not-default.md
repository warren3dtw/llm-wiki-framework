# 未知不是預設：先補這次工作需要的資訊，不猜

- 代號：agent:note/project-harness-003-unknown-is-not-default
- 類型：筆記・規則
- 摘要：尺寸、公差、版本、指令和工具名稱不知道就寫「待確認」並問；只問會影響這次工作的
- 出處：Rhino-init 工作專案快照（2026-11-14），init.md 規格 2.2 「全部文件寫入規則」「docs/PROJECT.md」
- 狀態：草稿，還沒有經過作者確認

agent 最容易出錯的地方，是把沒有人說過的值當成常見值直接用。之後出錯時，也分不清那個值是誰決定的。

## 規則

- 不猜指令、尺寸、公差、版本或工具名稱。不知道就寫「待確認」，並寫明影響哪一項工作、什麼時候之前要確認。
- 只問會擋住這次工作的缺口，不要求一次填完未來可能需要的資料。
- 不知道的值擋住依賴它的工作，但不擋住其他工作。例如公差未知，不妨礙建立空的專案結構，但不能拿來做依賴公差的驗收。
- 真正未知寫「待確認」，不適用寫「不適用：原因」，沒有紀錄寫「目前無紀錄」。不留未解析的佔位符。
- 專案的事實只寫在一個地方，其他文件引用它，不複製數值。

## 成立條件

工作會依賴使用者、專案或外部工具才知道的資訊。

## 不適用的情況

有權威來源可以查的事實（例如規範的條文），先查來源，查不到才當成未知。
