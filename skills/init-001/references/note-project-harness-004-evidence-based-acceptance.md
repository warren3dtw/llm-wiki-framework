# 驗收要有證據：結果只分通過、失敗、未執行、不適用

- 代號：agent:note/project-harness-004-evidence-based-acceptance
- 類型：筆記・規則
- 摘要：沒有證據不算通過；勾選任務、檔案存在、讀過程式都不等於驗收
- 出處：Rhino-init 工作專案快照（2026-11-14），init.md 規格 2.2 「docs/TESTING.md」「Phase 6」
- 狀態：草稿，還沒有經過作者確認

「做完了」和「驗收過了」是兩件事。沒有證據的「通過」會讓之後的人以為可以依賴它。

## 規則

- 結果只用四種：通過、失敗、未執行、不適用。不適用要寫原因。
- 每一條驗收都記：做了什麼操作或指令、輸入和產物的版本、預期、實際、證據在哪裡。
- 沒有證據不得標通過。勾選了任務、檔案存在、讀過程式碼，都不等於驗收。
- 沒有環境可以測時標「未執行」，不編造指令或結果。
- 只讀程式不能宣稱畫面、幾何或輸出檔通過；截圖也不能取代數值檢查。
- 使用者要親自確認的項目，在確認前維持「待審查」。

## 成立條件

產物要交給別人用，或之後的工作要依賴它。

## 不適用的情況

純粹的探索或草稿，事先說好不需要驗收的。
